## 🏆 Featured Projects

### 🛡️ Essentia · User Management System
Admin panel and API with fine-grained, role-based access control.
- **Frontend:** Next.js, TypeScript and Feature-Sliced Design, with reusable UI components and dynamic RBAC
- **Backend:** Express.js, Prisma and SQL Server, with permission modeling and index tuning for fast, secure queries
- **Ops:** Windows Server 2022 with IIS and PM2 for zero-downtime restarts, auto-recovery and centralized logs

### 🅿️ [Mulligan Parking System](https://github.com/Matan-Shabi/Mulligan-Parking-Distributed-System)
Fully distributed, fault-tolerant parking management with AI-powered recommendations.
- Spring Boot and Express.js services
- 3-node MongoDB replica set and 3-node RabbitMQ cluster
- Recommender service running as 3 managed replicas

### 🎮 [WorldOfGame](https://github.com/Matan-Shabi/WorldOfGame)
Python mini-games platform built around a full CI/CD workflow.
- Jenkins pipeline automating build, test and deploy
- Docker and Docker Compose for consistent multi-container environments
- Selenium end-to-end tests for the web leaderboard
- Memory Game, Number Guessing and Currency Roulette, with persistent scores and a cross-platform CLI

### 📚 [ScholarShareNet](https://scholarsharenet.vercel.app/)
Study-material sharing platform where students upload resources, collaborate and earn academic ratings.
- React, Node.js and MongoDB, deployed on Vercel and Heroku
- Repos: [client](https://github.com/JamalM02/SuperIdea-client) · [server](https://github.com/JamalM02/SuperIdea-server)
